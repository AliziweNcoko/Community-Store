# Deploying Community Store to Vercel ⚡

Vercel is significantly faster, completely free, and takes under **30 seconds** to deploy!

---

## 🚀 3 Easy Steps to Deploy on Vercel:

### Step 1: Push latest changes to GitHub
In AI Studio, make sure your latest code is pushed to your GitHub repository (`AliziweNcoko/Community-Store`).

---

### Step 2: Import Project on Vercel
1. Go to [https://vercel.com](https://vercel.com) and sign in with GitHub.
2. Click the **"Add New..."** button (top right) ➔ **"Project"**.
3. Find your repository: **`AliziweNcoko/Community-Store`** and click **"Import"**.

---

### Step 3: Configure & Deploy (Takes 30 seconds!)

* **Option A (React App - Default):**
  * Leave settings as default, or set:
    * **Root Directory:** click `Edit` ➔ select `web`
    * **Framework Preset:** Vite (auto-detected)
  * Click **"Deploy"**!

* **Option B (Vue 3 App):**
  * Set **Root Directory:** click `Edit` ➔ select `vue`
  * **Framework Preset:** Vite (auto-detected)
  * Click **"Deploy"**!

---

### 🎉 Your App is Live!
Vercel will give you a permanent, ultra-fast global URL:
`https://community-store-aliziwencoko.vercel.app` with automatic HTTPS SSL and instant updates on every git commit.
